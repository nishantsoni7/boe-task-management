# BOE Task Management System — Project Context

## Company

Best of Exports
Hospitality Furniture Manufacturing
Jodhpur, Rajasthan, India

---

# Project Objective

Build a cloud-based internal operational accountability system for Best of Exports.

The long-term vision is a modular internal operating system for BOE.

Phase 1 focuses ONLY on task management and operational accountability.

---

# Current Phase

## Operational Refinement Phase

The project is NO LONGER in architecture planning stage.

Core architecture already exists and is stable.

The current focus is:

* operational UX refinement
* accountability clarity
* navigation consistency
* mobile-first interaction polish
* workflow optimization
* low-friction task updates
* scalable operational behavior

Do NOT restart architecture planning.

Do NOT redesign the app from scratch.

Do NOT rebuild navigation or layout systems unless explicitly instructed.

---

# Product Philosophy

The software should feel:

* faster than WhatsApp
* easier than ClickUp
* simpler than ERP systems
* usable by non-technical employees
* frictionless for daily operational use

Every feature should reduce:

* verbal follow-up
* manual coordination
* dependency on memory
* manager micromanagement
* update resistance

---

# Core Product Principle

The system should make it:

1. Easier to give honest updates
2. Harder to avoid accountability

If a feature helps people appear busy without improving accountability, it should not be added.
