## Mandatory Platform Standards

The following documents define platform-wide standards and must be reviewed before creating, modifying, or proposing any module:

- BOE_GLOBAL_NAVIGATION_STANDARD.md
- BOE_MODULE_LAYOUT_STANDARD.md

These standards apply to all current and future BOE modules.

No module should be created or redesigned without complying with these standards.
