Company Name:
Best of Exports

Industry:
Hospitality Furniture Manufacturing

Primary Goal:
Build a cloud-based internal operating system for Best of Exports.

Phase 1 Goal:
Develop a very simple and easy-to-use task management system.

Important Philosophy:
The software should feel faster and easier than WhatsApp and ClickUp.

Target Users:
Sales team
BDM
Management
Operations team
Design team
Purchase team

Main Objective:
Reduce dependency on verbal communication and manual follow-up.

Important UX Rules:
- Very simple UI
- Mobile-first experience
- Minimum typing
- One-click updates wherever possible
- Very low resistance for employees
- Fast updates
- Clear accountability
- Easy delegation
- Daily usage habit creation

Phase 1 Features:
1. Task creation
2. Task assignment
3. Delegation
4. Daily task updates
5. Completion updates
6. Priority system
7. Deadline tracking
8. Escalation system
9. Dashboard
10. Notifications

Task Types:
1. Daily Update Task
2. Completion-Based Task

Escalation Logic:
- No update for 24 hours = Caution Zone
- No update for 48 hours = Danger Zone
- No update for 72 hours = Escalation to senior

Task Status:
- Pending
- Started
- Working
- Waiting
- Completed
- Blocked

Task Ownership Structure:
- Created By
- Assigned To
- Delegated By
- Current Owner

Future Modules:
1. Attendance Management
2. Salary Calculation
3. Incentive Management
4. Lead Master Data
5. Lead Pipeline Tracking
6. Cab Booking
7. ClickUp API Sync
8. Auto Task Assignment
9. Reports and Rankings

Lead Master Rules:
- Phone number must always be unique
- Duplicate phone numbers should not be allowed
- System should show existing owner if duplicate exists

Technology Preference:
Cloud-based
Mobile + Desktop access
API friendly
Scalable architecture

Preferred Stack:
Frontend: React / Next.js
Backend: Supabase
Hosting: Vercel

Important Note:
The system should be developed module by module slowly and optimized over time based on actual team behavior and operational learnings.
